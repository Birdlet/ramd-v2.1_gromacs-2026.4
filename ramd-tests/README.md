# RAMD test suites (GROMACS 2026.4)

Functional test suites for the RAMD feature. They drive the installed
`gmx` binary and use the systems from `src/testutils/simulationdatabase`.

## Contents

| Path | Description |
|------|-------------|
| `run_ramd_tests.sh` | CPU functional tests |
| `run_ramd_gpu_tests.sh` | GPU functional tests |
| `setup.sh` | Generates the reference `.tpr` files in `tpr/` |
| `mdp/` | mdp files used to generate the reference tpr files |
| `tpr/` | Reference tpr files (generated by `setup.sh`) |

## Reference tpr files

`setup.sh` produces:

* `tpr/1wdhi_ramd.tpr` — 1WDHI, 1 RAMD group (Protein/INH).
* `tpr/water4_ramd2grp.tpr` — 4water, 2 RAMD groups.
* `tpr/glyr_ramd5grp.tpr` — GlyR, 5 RAMD groups.

The test scripts generate their own tpr files at run time; the ones in `tpr/`
are archived reference artifacts. Regenerate them with:

```bash
./setup.sh                 # or: ./setup.sh /path/to/gmx-prefix
```

## Running the CPU suite

```bash
./run_ramd_tests.sh                 # quick
./run_ramd_tests.sh --full          # include the heavy GlyR 5-group case
./run_ramd_tests.sh --list
./run_ramd_tests.sh --test ramd_basic --test connected_ligands
./run_ramd_tests.sh --keep          # keep per-test work dirs
./run_ramd_tests.sh --prefix /opt/gromacs-2026.4-ramd
```

Tests: `version`, `mdp_parse`, `ramd_basic`, `ramd_output_optin`,
`multigroup2`, `connected_ligands`, `restart_append`, `old_angle_dist`,
`nonramd_control`, `reprod`, `glyr_multigroup5`.

## Running the GPU suite

```bash
./run_ramd_gpu_tests.sh
./run_ramd_gpu_tests.sh --full --update
./run_ramd_gpu_tests.sh --gpu-id 1
./run_ramd_gpu_tests.sh --gpu-flags "-nb gpu -pme gpu"
```

Tests: `gpu_build_check`, `gpu_probe`, `gpu_nb_pme_1wdhi`,
`gpu_cpu_consistency`, `gpu_multigroup2`, `gpu_pmefft`, `gpu_nb_only`,
`gpu_update`, `gpu_multi_gpu`.

GPU tests are reported as `SKIP` (not `FAIL`) when no usable GPU is present or
when a platform limitation applies.

## CTest / `make test` integration

The suites are registered with CTest from
`src/gromacs/ramd/tests/CMakeLists.txt`. Configure with:

| Option | Default | Effect |
|--------|---------|--------|
| `GMX_BUILD_RAMD_SHELL_TESTS` | `ON` | register the CPU suite as `RamdShellTestsCpu` |
| `GMX_BUILD_RAMD_SHELL_GPU_TESTS` | `OFF` | register the GPU suite as `RamdShellTestsGpu` |

After building, run them with:

```bash
ctest -R RamdShell                 # both registered RAMD shell suites
ctest -R RamdShellTestsCpu
ctest -R "[Rr]amd"                 # RAMD shell suites + C++ tests
ctest -R RamdShell -V              # verbose
```

The CTest entries invoke the scripts with `--gmx <built gmx>` and set
`GMXDATA`/`GMXLIB` to the source tree, so they work without installing. The
CPU suite is registered as `--quick`; enable `--full`/GPU cases by editing the
`add_test` invocation or by running the scripts directly.

## Notes

* The RAMD output file is an optional output file: pass `-ramd` to `mdrun` to
  write it (the scripts do this).
* `mdrun` is forced to CPU execution for the CPU suite (`-nb cpu -pme cpu`) and
  to GPU where requested.
* For known limitations see `../README.md` and `../03-已知限制-RAMD-2026.4.md`.
